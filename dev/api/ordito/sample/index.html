ordito.sample

Generative sampling: new points on a mesh surface, inside its volume, or over a sphere.

Everything here creates points -- uniformly over the faces (sample_surface), spaced at least radius apart (sample_surface_poisson_disk, sample_surface_blue_noise), any of the three over only the part of the surface inside a ball (sample_surface_in_ball), inside a watertight solid (sample_volume), or over a sphere, hemisphere or cone as a low-discrepancy Fibonacci lattice (the sample_fibonacci_* family, which take a count and no mesh at all).

Subsampling an existing cloud is the other question and lives with the data structures that answer it: points.farthest_point_sample for an exact count, and voxels.voxel_down_sample for one representative per occupied cell. Neither belongs here -- each is a reduction of points a caller already has.

The one function here that reads like a subsampler and is not is sample_surface_blue_noise: it draws its own dense pool from the surface and thins that, so its input is a mesh and its output is new points, never a subset of anything the caller passed.

See Also

points.farthest_point_sample Subsample an existing cloud to an exact count. voxels.voxel_down_sample Subsample an existing cloud to one point per occupied voxel.

Generate near-uniform unit vectors inside a cone around +z.

The same Fibonacci-spiral construction as sample_fibonacci_sphere, with z descending uniformly through (cos(half_angle), 1) instead of the whole range — which is the correct restriction, because a uniform z is a uniform solid angle (Archimedes) whether the band is the full sphere or a cap. def sample_fibonacci_cone(
    count: int, half_angle: float, device: wp.DeviceLike = None
) -> wp.array[wp.vec3]:
    """
    Generate near-uniform unit vectors inside a cone around ``+z``.

    The same Fibonacci-spiral construction as
    [`sample_fibonacci_sphere`][ordito.sample.sample_fibonacci_sphere], with ``z`` descending
    uniformly through ``(cos(half_angle), 1)`` instead of the whole range — which is the *correct*
    restriction, because a uniform ``z`` is a uniform solid angle (Archimedes) whether the band is
    the full sphere or a cap. Rejection-sampling a sphere lattice down to the cone would not stay
    low-discrepancy; this does.

    Parameters
    ----------
    count
        Number of directions to generate.
    half_angle
        Half-angle of the cone in **radians**, measured from ``+z``. ``pi / 2`` reproduces
        [`sample_fibonacci_hemisphere`][ordito.sample.sample_fibonacci_hemisphere] and ``pi``
        reproduces [`sample_fibonacci_sphere`][ordito.sample.sample_fibonacci_sphere]. Must be in
        ``(0, pi]``.
    device
        Warp device for the result. Defaults to the current device.

    Returns
    -------
    wp.array[wp.vec3]
        ``(count,)`` unit vectors inside the cone. Empty when ``count`` is 0.

    Raises
    ------
    ValueError
        If ``half_angle`` is outside ``(0, pi]``.

    See Also
    --------
    [`sample_fibonacci_hemisphere`][ordito.sample.sample_fibonacci_hemisphere]
    [`ordito.visibility.shape_diameter`][ordito.visibility.shape_diameter]

    Examples
    --------
    Every direction is within ``30`` degrees of ``+z``:

    ```python
    import math

    import ordito as od

    directions = od.sample.sample_fibonacci_cone(200, math.radians(30.0)).numpy()
    print(directions.shape)  # (200, 3)
    print(bool((directions[:, 2] >= math.cos(math.radians(30.0)) - 1e-6).all()))  # True
    ```
    """
    if not 0.0 < half_angle <= math.pi:
        raise ValueError(f"half_angle must be in (0, pi] radians, got {half_angle}")
    return _fibonacci_lattice(count, 1.0 - math.cos(half_angle), device)

def sample_surface(
    vertices: wp.array[wp.vec3],
    faces: wp.array[wp.int32],
    count: int,
    face_weight: wp.array[wp.float32] | None = None,
    seed: int | None = None,
    *,
    return_barycentric: bool = False,
) -> (
    tuple[wp.array[wp.vec3], wp.array[wp.int32]]
    | tuple[wp.array[wp.vec3], wp.array[wp.int32], wp.array[wp.vec3]]
):
    """
    Sample points uniformly on a triangle mesh surface (area-weighted faces).

    Weights faces by their area by default. Builds a CDF and
    draws triangle indices by inverse-transform sampling it, then uniform points with
    ``wp.sample_triangle`` (same scheme as [`trimesh.sample.sample_surface`][]).

    Parameters
    ----------
    vertices
        ``(n_vertices,)`` vertex positions.
    faces
        ``(3 * n_faces,)`` flat triangle indices, ``(i0, i1, i2)`` per face.
    count
        Number of samples.
    face_weight
        ``(n_faces,)`` per-face weights. If ``None``,
        the triangle areas are used.
    seed
        RNG seed for ``wp.rand_init``. If ``None``, a random seed is chosen.
    return_barycentric
        If ``True``, also return each sample's barycentric coordinates in its face, which is what
        [`interpolate_barycentric`][ordito.interpolation.interpolate_barycentric] reads a
        per-vertex field (a colour, a UV, a normal) at the samples with.

    Returns
    -------
    samples
        ``(count,)`` sampled positions on the mesh surface.
    face_index
        ``(count,)`` triangle index for each sample.
    barycentric
        ``(count,)`` coordinates of each sample in its face, in corner order; only when
        ``return_barycentric`` is ``True``.

    Raises
    ------
    ValueError
        If ``face_weight`` is given and its length is not the triangle count, if the mesh has no
        faces and ``count > 0``, or if ``count > 0`` and the total face weight (the surface area,
        without ``face_weight``) is not positive.
    RuntimeError
        If ``vertices``, ``faces`` and ``face_weight`` are not all on one device.

    Notes
    -----
    A seeded draw repeats bit for bit on CUDA while [`deterministic`][ordito.config.deterministic]
    is on (the default).

    Examples
    --------
    Every sample lies on the unit cube's surface, on the face it reports:

    ```python
    import numpy as np

    import ordito as od

    vertices, faces = od.creation.box()
    samples, face_index = od.sample.sample_surface(vertices, faces, 1000, seed=0)
    print(samples.shape, face_index.shape)  # (1000,) (1000,)
    print(np.abs(samples.numpy()).max(axis=1).round(4).min())  # 0.5
    print(0 <= face_index.numpy().min() and face_index.numpy().max() < 12)  # True
    ```
    """
    require_same_device(vertices=vertices, faces=faces, face_weight=face_weight)
    n_faces = faces.size // 3
    # Validated before the ``count == 0`` short-circuit below, so a bad ``face_weight`` still
    # raises even when nothing would otherwise be sampled.
    if face_weight is not None and face_weight.size != n_faces:
        raise ValueError(
            f"face_weight length must match number of triangles (expected {n_faces}, "
            f"got {face_weight.size})"
        )
    barycentric = (
        _launch.empty(count, dtype=wp.vec3, device=vertices.device) if return_barycentric else None
    )
    if count == 0:
        points = _launch.empty(0, dtype=wp.vec3, device=vertices.device)
        face_index = _launch.empty(0, dtype=wp.int32, device=vertices.device)
    else:
        cdf, total = _face_cdf(vertices, faces, face_weight)
        points, face_index = _draw_surface_samples(
            vertices, faces, cdf, total, count, seed, barycentric
        )
    if barycentric is None:
        return points, face_index
    return points, face_index, barycentric

sample_surface_poisson_disk 

sample_surface_poisson_disk(
    vertices: array[vec3],
    faces: array[int32],
    count: int,
    init_factor: float = 5.0,
    face_weight: array[float32] | None = None,
    seed: int | None = None,
) -> tuple[wp.array[wp.vec3], wp.array[wp.int32]]

Sample points on a triangle mesh surface with Poisson disk distribution.

Uses Weighted Sample Elimination (Öztireli & Gross 2012): generates init_factor * count uniform surface samples, then iteratively removes the most "crowded" points in parallel rounds until count remain. Each round deletes, simultaneously, every alive point that is heavier than all of its alive neighbours and at least as heavy as the alive point ranked excess-th by weight (excess being how many deletions remain). Maximality is decided on (weight, -index), so no two of them are within r_max of each other, and the weight floor keeps the deletions in the global weight order that sequential elimination follows: the rounds keep the samples the sequential algorithm would keep.

(n_vertices,) vertex positions.

 required

(3 * n_faces,) flat triangle indices, (i0, i1, i2) per face.

 required
count int

Number of output samples.

 required
init_factor float

Over-sampling factor; initial pool has init_factor * count points. Must satisfy init_factor >= 1.

 5.0
face_weight array[float32] | None

(n_faces,) per-face weights passed to the initial uniform sampling, or None.

 None

RNG seed for the initial uniform sampling. If None, a random seed is chosen.

 None

Examples:

def sample_surface_poisson_disk(
    vertices: wp.array[wp.vec3],
    faces: wp.array[wp.int32],
    count: int,
    init_factor: float = 5.0,
    face_weight: wp.array[wp.float32] | None = None,
    seed: int | None = None,
) -> tuple[wp.array[wp.vec3], wp.array[wp.int32]]:
    """
    Sample points on a triangle mesh surface with Poisson disk distribution.

    Uses Weighted Sample Elimination (Öztireli & Gross 2012): generates
    ``init_factor * count`` uniform surface samples, then iteratively removes
    the most "crowded" points in parallel rounds until ``count`` remain.
    Each round deletes, simultaneously, every alive point that is heavier than all of its alive
    neighbours and at least as heavy as the alive point ranked ``excess``-th by weight (``excess``
    being how many deletions remain). Maximality is decided on ``(weight, -index)``, so no two of
    them are within ``r_max`` of each other, and the weight floor keeps the deletions in the global
    weight order that sequential elimination follows: the rounds keep the samples the sequential
    algorithm would keep.

    Parameters
    ----------
    vertices
        ``(n_vertices,)`` vertex positions.
    faces
        ``(3 * n_faces,)`` flat triangle indices, ``(i0, i1, i2)`` per face.
    count
        Number of output samples.
    init_factor
        Over-sampling factor; initial pool has ``init_factor * count`` points.
        Must satisfy ``init_factor >= 1``.
    face_weight
        ``(n_faces,)`` per-face weights passed to the initial uniform sampling, or ``None``.
    seed
        RNG seed for the initial uniform sampling. If ``None``, a random seed
        is chosen.

    Returns
    -------
    samples
        ``(count,)`` sampled positions on the mesh surface.
    face_index
        ``(count,)`` triangle index for each sample.

    Raises
    ------
    ValueError
        If ``init_factor < 1``, or if ``count > 0`` and the mesh has no faces or a total face
        weight (the surface area, without ``face_weight``) that is not positive.
    RuntimeError
        If ``vertices``, ``faces`` and ``face_weight`` are not all on one device.

    Examples
    --------
    ```python
    import ordito as od

    vertices, faces = od.creation.icosphere(subdivisions=3)
    samples, face_index = od.sample.sample_surface_poisson_disk(vertices, faces, 200, seed=0)
    print(samples.shape)  # (200,)
    _, spacing = od.neighbors.query_nearest(samples, samples, 2)
    print(f"{spacing.numpy()[:, 1].min():.1f}")  # 0.2
    ```
    """
    require_same_device(vertices=vertices, faces=faces, face_weight=face_weight)
    device = vertices.device

    # Validated before the ``count == 0`` short-circuit below, matching ``sample_surface``.
    if init_factor < 1.0:
        raise ValueError(f"init_factor must be >= 1, got {init_factor}")

    if count == 0:
        return (
            _launch.empty(0, dtype=wp.vec3, device=device),
            _launch.empty(0, dtype=wp.int32, device=device),
        )

    init_count = max(math.ceil(init_factor * count), count)

    # 1. Initial uniform surface samples, and 2. the surface area for the radius: the total of the
    # area CDF the pool is drawn from, unless the pool is drawn by other weights.
    if face_weight is None:
        cdf, surface_area = _face_cdf(vertices, faces, None)
        init_points, init_face_indices = _draw_surface_samples(
            vertices, faces, cdf, surface_area, init_count, seed
        )
    else:
        init_points, init_face_indices = sample_surface(
            vertices, faces, init_count, face_weight=face_weight, seed=seed
        )
        _, areas = face_normals_and_areas(vertices, faces)
        surface_area = float(cast("float", wp.utils.array_sum(areas)))

    return _eliminate_to_count(init_points, init_face_indices, count, surface_area)

def sample_surface_in_ball(
    vertices: wp.array[wp.vec3],
    faces: wp.array[wp.int32],
    center: wp.vec3,
    radius: float,
    count: int | None = None,
    *,
    method: Literal["uniform", "poisson_disk", "blue_noise"] = "uniform",
    spacing: float | None = None,
    init_factor: float = 5.0,
    seed: int | None = None,
) -> tuple[wp.array[wp.vec3], wp.array[wp.int32]]:
    """
    Sample the part of a triangle mesh surface that lies inside a ball.

    The samples cover exactly the surface within ``radius`` of ``center``, faces crossing the
    sphere included: every face whose closest point to ``center`` lies in the ball is drawn from,
    even when all its corners and its centroid lie outside, and the samples landing outside the
    ball are discarded. No submesh is built; the faces outside the ball get zero weight in the
    draw.

    Parameters
    ----------
    vertices
        ``(n_vertices,)`` vertex positions.
    faces
        ``(3 * n_faces,)`` flat triangle indices, ``(i0, i1, i2)`` per face.
    center
        Center of the ball.
    radius
        Radius of the ball (closed: a sample at distance ``radius`` is inside).
    count
        Number of samples, for ``"uniform"`` and ``"poisson_disk"``. Must be ``None`` for
        ``"blue_noise"``, whose count follows from ``spacing``.
    method
        How the samples are spread over the surface in the ball:

        - ``"uniform"`` (default): ``count`` independent, uniformly distributed samples, as
          [`sample_surface`][ordito.sample.sample_surface] draws over a whole mesh.
        - ``"poisson_disk"``: ``count`` samples by weighted sample elimination of a uniform pool
          of ``init_factor * count`` samples in the ball, as
          [`sample_surface_poisson_disk`][ordito.sample.sample_surface_poisson_disk].
        - ``"blue_noise"``: a maximal set of samples no two closer than ``spacing``, as
          [`sample_surface_blue_noise`][ordito.sample.sample_surface_blue_noise].
    spacing
        Minimum distance between samples, for ``"blue_noise"`` only.
    init_factor
        Over-sampling factor of the ``"poisson_disk"`` pool. Must satisfy ``init_factor >= 1``.
    seed
        RNG seed. If ``None``, a random seed is chosen. With a seed the output is reproducible.

    Returns
    -------
    samples
        ``(m,)`` sampled positions on the surface inside the ball: ``m`` is ``count`` for
        ``"uniform"`` and ``"poisson_disk"`` (see Notes), and follows from ``spacing`` and the
        area inside the ball for ``"blue_noise"``.
    face_index
        ``(m,)`` triangle index for each sample.

    Raises
    ------
    ValueError
        If ``method`` is not one of the options, if ``radius`` is not positive, if ``count`` is
        missing or negative for ``"uniform"`` / ``"poisson_disk"``, if ``spacing`` is missing or
        not positive for ``"blue_noise"``, if the argument the method does not take is given, or
        if ``init_factor < 1`` for ``"poisson_disk"``.
    RuntimeError
        If ``vertices`` and ``faces`` are not on one device.

    Notes
    -----
    A ball that meets no face, or meets the surface in a set of no area, returns two empty arrays.
    The uniform pool is drawn over the faces meeting the ball and the samples outside it rejected,
    so its cost grows with the area of those faces against the area inside the ball; a ball
    covering less than about one part in ``2**24`` of the faces it meets can return fewer than
    ``count`` samples.

    Examples
    --------
    A ball of radius 0.1 centred on a face of the unit cube, away from every vertex:

    ```python
    import numpy as np
    import warp as wp

    import ordito as od

    vertices, faces = od.creation.box()
    center = wp.vec3(0.5, 0.1, 0.2)
    samples, _ = od.sample.sample_surface_in_ball(vertices, faces, center, 0.1, 500, seed=0)
    print(samples.shape)  # (500,)
    offsets = samples.numpy() - np.array([0.5, 0.1, 0.2])
    print(bool(np.linalg.norm(offsets, axis=1).max() <= 0.1))  # True
    print(np.abs(offsets[:, 0]).max().round(4))  # 0.0
    ```
    """
    require_same_device(vertices=vertices, faces=faces)
    device = vertices.device
    if method not in _BALL_METHODS:
        raise ValueError(f"method must be one of {_BALL_METHODS}, got {method!r}")
    if not radius > 0.0:
        raise ValueError(f"radius must be > 0, got {radius}")
    if method == "blue_noise":
        if spacing is None or not spacing > 0.0:
            raise ValueError(f"method='blue_noise' takes a spacing > 0, got {spacing}")
        if count is not None:
            raise ValueError(
                "method='blue_noise' derives its count from spacing; count must be None"
            )
    else:
        if count is None or count < 0:
            raise ValueError(f"method={method!r} takes a count >= 0, got {count}")
        if spacing is not None:
            raise ValueError(f"method={method!r} takes a count; spacing must be None")
        if method == "poisson_disk" and init_factor < 1.0:
            raise ValueError(f"init_factor must be >= 1, got {init_factor}")

    empty = (
        _launch.empty(0, dtype=wp.vec3, device=device),
        _launch.empty(0, dtype=wp.int32, device=device),
    )
    if faces.size == 0 or count == 0:
        return empty
    radius_sq = radius * radius
    # The faces reaching into the ball weighted by area, every other face by zero, and the total:
    # the area the draws cover, of which the part inside the ball is what they keep.
    cdf, hit_area, box = _face_cdf_and_vertex_box(vertices, faces, center, radius_sq)
    if not hit_area > 0.0:
        return empty

    if method == "blue_noise":
        assert spacing is not None
        # The pool at the whole-surface sampler's density over the faces meeting the ball, pruned
        # to the ball: the dart throw then packs the surface inside the ball alone, its border
        # included. The grid only has to enclose the pruned pool: the vertices' box cut to the
        # ball's.
        pool_size, pool_seed, priority_seed = _blue_noise_pool(hit_area, spacing, seed)
        points, face_index, flags = _draw_ball_round(
            vertices, faces, cdf, hit_area, center, radius_sq, pool_seed, 0, pool_size
        )
        points, face_index = _emit_kept_samples(flags, points, face_index)
        lower, upper = box
        lower = wp.vec3(*(max(float(lower[a]), float(center[a]) - radius) for a in range(3)))
        upper = wp.vec3(*(min(float(upper[a]), float(center[a]) + radius) for a in range(3)))
        return _dart_throw_blue_noise(points, face_index, spacing, priority_seed, (lower, upper))

    assert count is not None
    target = count if method == "uniform" else max(math.ceil(init_factor * count), count)
    points, face_index, area = _draw_ball_pool(
        vertices, faces, cdf, hit_area, center, radius_sq, target, seed
    )
    if method == "uniform":
        return points, face_index
    return _eliminate_to_count(points, face_index, count, area)

def sample_volume(
    vertices: wp.array[wp.vec3], faces: wp.array[wp.int32], count: int, seed: int | None = None
) -> wp.array[wp.vec3]:
    """
    Sample points uniformly inside a watertight triangle mesh volume.

    Fans tetrahedra from the mesh's area-weighted surface centroid, builds a CDF
    from signed tetrahedron volumes, and draws uniform points inside each selected one via
    the order-statistics barycentric method (zero rejection for meshes that are
    star-shaped with respect to their centroid).

    Parameters
    ----------
    vertices
        ``(n_vertices,)`` vertex positions.
    faces
        ``(3 * n_faces,)`` flat triangle indices, ``(i0, i1, i2)`` per face.
    count
        Number of samples.
    seed
        RNG seed for ``wp.rand_init``. If ``None``, a random seed is chosen.

    Returns
    -------
    samples
        ``(count,)`` positions inside the mesh volume.

    Raises
    ------
    ValueError
        If the mesh is not watertight (open boundary edges detected).
    ValueError
        If the mesh has zero total volume, some signed tetrahedron volumes are negative after
        fanning from the centroid (the mesh is not star-shaped with respect to its own centroid,
        e.g. a torus), or the mesh has no faces and ``count > 0``.
    RuntimeError
        If ``vertices`` and ``faces`` are not all on one device.

    Examples
    --------
    Every sample lies inside the unit cube:

    ```python
    import numpy as np

    import ordito as od

    vertices, faces = od.creation.box()
    samples = od.sample.sample_volume(vertices, faces, 1000, seed=0)
    print(samples.shape)  # (1000,)
    print(bool((np.abs(samples.numpy()) <= 0.5).all()))  # True
    ```
    """
    require_same_device(vertices=vertices, faces=faces)
    n_faces = faces.size // 3

    # These two validations run regardless of ``count`` -- unlike the "no faces" guard below,
    # which only matters once something is actually being sampled -- so a caller cannot skip a
    # documented raise on a malformed mesh by asking for zero points. The check's readback stays
    # ahead of the volume launches, though issuing them first would let one wait serve both reads:
    # it also range-checks the faces, and the volume kernels would read past ``vertices`` first.
    if not od.validation.is_edge_manifold(
        faces, allow_boundary_edges=False, n_vertices=vertices.size
    ):
        raise ValueError(
            "mesh is not watertight; tetrahedral decomposition requires a closed surface"
        )

    # The signed tetrahedron volumes are written straight into the CDF buffer, whose one extra slot
    # flags a negative volume; the scan turns the face slots into the CDF in place, and one
    # readback brings back the total (the scan's last element) and the flag together, so the
    # star-shaped test needs no separate ``min`` reduction. The empty mesh, where "no negative
    # volumes" holds vacuously, launches nothing.
    total_vol = 0.0
    center = None
    cdf = None
    if n_faces > 0:
        # Every face slot is written by the volume pass and the flag slot is cleared by the
        # centroid pass before it, so the buffer starts uninitialized.
        cdf = _launch.empty(n_faces + 1, dtype=wp.float32, device=vertices.device)
        center = _surface_centroid_on_device(vertices, faces, cdf)
        _launch.launch(
            kernel_sample.tetrahedron_volumes_flag_negative,
            dim=n_faces,
            inputs=[vertices, faces, center],
            outputs=[cdf],
            device=vertices.device,
        )
        face_slots = _launch.view(cdf, 0, n_faces)
        _launch.array_scan(face_slots, out_array=face_slots)
        # Sizes nothing but decides two raises and scales the sampling kernel's draws.
        total_vol, negative = read_values(cdf, n_faces - 1, 2)
        if negative != 0.0:
            raise ValueError(
                "mesh is not star-shaped with respect to its centroid (e.g. a torus); "
                "tetrahedral decomposition cannot sample it without rejection"
            )

    if count == 0:
        return _launch.empty(0, dtype=wp.vec3, device=vertices.device)

    if n_faces == 0:
        raise ValueError("mesh has no faces; cannot sample its volume")

    if total_vol == 0.0:
        raise ValueError("mesh has zero volume")
    # n_faces > 0 here, so the volume pass computed both.
    assert center is not None
    assert cdf is not None
    cdf = _launch.view(cdf, 0, n_faces)

    out_points = _launch.empty(count, dtype=wp.vec3, device=vertices.device)
    _launch.launch(
        kernel_sample.sample_volume_tetrahedra,
        dim=count,
        inputs=[
            vertices,
            faces,
            center,
            cdf,
            wp.float32(total_vol),
            resolve_seed(seed),
            out_points,
        ],
        device=vertices.device,
    )
    return out_points

The resolve_* pattern

Both of these -- this and sample.resolve_seed / voxels.resolve_voxel_grid -- turn an optional argument into the concrete value the wrapper would have derived, so a caller who wants two functions to share the derived thing can resolve it once and pass it to both. def resolve_seed(seed: int | None) -> int:
    """
    Concrete non-negative ``int32``-range RNG seed, drawn at random when none was given.

    Every generator in the package takes ``seed: int | None`` and means the same thing by it, so
    the draw lives here rather than at each entry point. Public because
    [`random_soup`][ordito.creation.random_soup] needs the identical convention from another
    module.

    Parameters
    ----------
    seed
        User-provided seed, or ``None`` to draw a cryptographically random one.

    Returns
    -------
    int
        ``seed`` unchanged when provided, otherwise a random value in ``[0, 2**31)``.

    See Also
    --------
    [`sample_surface`][ordito.sample.sample_surface]
    [`random_soup`][ordito.creation.random_soup]
    [`voxels.resolve_voxel_grid`][ordito.voxels.resolve_voxel_grid]

    Notes
    -----
    !!! note "The ``resolve_*`` pattern"
        Both of these -- this and [`sample.resolve_seed`][ordito.sample.resolve_seed] /
        [`voxels.resolve_voxel_grid`][ordito.voxels.resolve_voxel_grid] -- turn an optional
        argument into the concrete value the wrapper would have derived, so a caller who wants two
        functions to share the derived thing can resolve it once and pass it to both. Each default
        is domain knowledge, so they cannot share a module. The optional face-adjacency pair
        deliberately has **no** such resolver: deriving it is one
        [`face_adjacency`][ordito.adjacency.face_adjacency] call with ``return_edges=True``, so
        only the *pairing rule* is worth sharing and
        [`adjacency.require_paired_adjacency`][ordito.adjacency.require_paired_adjacency] is that
        rule on its own.

    Examples
    --------
    ```python
    import ordito as od

    print(od.sample.resolve_seed(7))  # 7
    print(0 <= od.sample.resolve_seed(None) < 2**31)  # True
    ```
    """
    if seed is None:
        return secrets.randbelow(2**31)
    return int(seed)
